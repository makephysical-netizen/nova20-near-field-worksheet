Evaluating low objects with NOVA20

If a robot's existing sensor misses low objects, start with a measurable question: at which positions do you need a reliable distance input? A second sensor is useful only if its rays can reach those positions and its data add information the current system lacks.

This short worksheet helps plan a bench test. It does not claim that NOVA20 will detect a particular obstacle or make a robot safe.

1. Draw the missing region

In robot coordinates, mark the object height, front-face distance and lateral position that the current system misses. Record the current sensor's mounting height and the robot body that may block its view. Note whether the issue is a true measurement gap or a software filtering/configuration problem.

For NOVA20, the V2.1 datasheet describes 20 channel-tagged distance readings across a field of view of up to 40°, at 10 Hz. Its stated 1 m range applies to the specified 10% reflectivity and 100 klux condition. That is enough to plan a short-range trial, not to infer detection probability or stopping performance.

Try the mounting geometry worksheet to reject obvious placement mistakes. The tool estimates nominal ray crossings with a low object's height band; it is not an optical or safety model.

2. Make one repeatable measurement

  1. Fix the robot or sensor on a bench. Use a ruler or marked floor to set several known object distances, including positions just outside the expected range.
  2. Use a low object representative of the real task. Repeat with at least one dark or low-reflectivity surface and the expected ambient light. Keep the target pose and sensor mount fixed for each series.
  3. Log raw channel ID, range, signal strength, invalid/missing returns, host timestamp and target distance. Do not collapse all channels into one “detected” flag yet.
  4. Repeat at nearby lateral positions, then test with the full robot body installed to expose occlusion. Compare with the current sensor at the same positions.

3. Decide what the test established

A useful result is a map of positions where the new raw channel data are present and the existing sensor has no useful reading. If both sensors return data but the robot still misses the object, inspect calibration, filtering and decision thresholds before assuming another sensor is needed.

Keep the boundary clear. Twenty angular samples are not a full 3D scene. Range, accuracy and frame rate are specified under stated conditions; they do not establish object classification, obstacle avoidance performance or safe stopping. The V2.1 datasheet gives no enclosure protection rating. Outdoor use needs a separate enclosure and environmental evaluation.

For wiring, frame parsing and pin assignments, follow the current official user manual for your hardware revision; this draft deliberately does not guess those details.
